# Glossario

Termini e sigle usati nella wiki.

| Termine | Significato |
|---|---|
| **Punteggio v2** | Punteggio da 0 a 100 della scala del [[Protocollo di discovery]]: 11 criteri (C1-C11) con pesi fissati prima della valutazione, meno eventuali penalità. "v2" indica la seconda versione della scala, usata in questa discovery. |
| **C1-C11** | I criteri della scala: C1 bisogno, C2 domanda, C3 monetizzazione, C4 vantaggio delle competenze, C5 distribuzione senza pubblico, C6 resistenza all'AI generalista, C7 difendibilità, C8 debolezza dei concorrenti, C9 tempo al primo euro, C10 delegabilità, C11 tetto di ricavo a 24 mesi. |
| **Lordo** | Punteggio prima delle penalità. |
| **Penalità di conflitto** | Sottrazione per il rischio di conflitto con il lavoro attuale: −8 se l'idea vende dati o servizi di scraping a terzi, −2 se lo scraping è uno strumento interno, −1 se serve solo a trovare opportunità, 0 se non c'entra. Vedi [[Classifica]]. |
| **Primo giro / secondo giro** | Primo giro: ogni ipotesi esaminata da Entusiasta, Bucatore e Giudice. Secondo giro: approfondimento delle 4 idee scelte, con un nuovo confronto. |
| **Entusiasta / Bucatore di palloncini / Giudice** | I tre ruoli della discovery: chi costruisce il caso a favore, chi cerca di smentirlo, chi verifica e decide. |
| **Obiettivi A, B, C** | A = reddito extra di 1-2 k€/mese netti (~21-43 k€/anno di margine prima delle tasse); B = business da almeno 50 k€/anno di margine entro 24 mesi, con il founder a non più di 5 ore/settimana dopo l'avvio; C = costruire (o comprare e migliorare) un asset e venderlo entro 12-18 mesi dall'avvio. Vedi [[Classifica per obiettivo]]. |
| **Gate** (nelle note anche **cancello**) | Condizione da superare prima di tutto (es. autorizzazione del datore, parere legale, capitale): senza, l'idea è ferma. |
| **Kill / stop / criterio di arresto** | Risultato che, se si verifica durante un esperimento, fa fermare l'idea. |
| **Confutata / parziale / incerta** | Esito di un'ipotesi: smentita dalle evidenze / vera solo in una forma ristretta / evidenze insufficienti per decidere. |
| **[fatto] / [stima]** | Dato verificato su una fonte / valutazione con il ragionamento dichiarato. |
| **B2B / B2C** | Vendita ad aziende / a consumatori. |
| **Founder** | Chi avvia il progetto (qui: l'utente). |
| **SEO** | Ottimizzazione per farsi trovare su Google. |
| **FTE** | Equivalente a tempo pieno (1 FTE = una persona a tempo pieno). |
| **Earn-out / pagamento differito** | Parte del prezzo di acquisto pagata dopo, in base ai risultati. |
| **White label** | Prodotto venduto da un'altra azienda con il proprio marchio. |
| **KPI** | Indicatori chiave misurati per decidere. |
| **SLA** | Livello di servizio garantito per contratto. |
| **LOI** | Lettera d'intenti: impegno scritto non vincolante. |
| **CAC / LTV** | Costo per acquisire un cliente / valore totale di un cliente nel tempo. |
| **CPC** | Costo per clic nella pubblicità online. |
| **ARPU / ARPA** | Ricavo medio per utente / per account. |
| **ASO** | Ottimizzazione per farsi trovare negli store di app. |
| **SKU** | Singolo articolo di un catalogo. |
| **GTIN / MPN** | GTIN: famiglia di codici standard di prodotto di cui fa parte l'EAN. MPN: codice del produttore. |
| **MAP** | Prezzo minimo pubblicizzato imposto da un marchio ai rivenditori. |
| **PEC** | Posta elettronica certificata, con valore legale. |
| **ADR** | Risoluzione alternativa delle controversie (es. conciliazioni, arbitro dell'energia). |
| **MCP** | Protocollo con cui le applicazioni AI si collegano a fonti di dati e strumenti esterni. |
| **Subagenti** | Gli agenti di ricerca (Entusiasta e Bucatore) avviati dal Giudice di ogni sessione. |
| **Round 2** | Secondo giro. |
| **Bot / anti-bot** | Programma automatico che visita i siti / protezioni dei siti contro i programmi automatici. |
| **Margine / margine lordo** | Margine: quanto resta dopo tutti i costi, prima delle tasse. Margine lordo: prima di operatore, costi fissi della società e infrastruttura. |
| **AI** | Intelligenza artificiale. |
| **Ranking** | Posizione in una classifica (es. di un'offerta su un'agenzia online). |
| **Back office** | Lavoro amministrativo e di gestione delle pratiche. |
| **Regole di separazione** | Precauzioni per tenere il progetto separato dal lavoro: codice scritto da zero, infrastruttura propria, nessun ex collega senza parere (passo 5 di [[I-H16-1 Autorizzazione scritta e veicolo societario]]). |
| **Zona grigia** | Esito intermedio di un esperimento: né successo né stop; si ripete prima di investire. |
| **Margine di contribuzione** | Ricavi meno i costi variabili di ogni cliente (es. accesso ai siti, calcolo), prima dei costi fissi e del personale. |
| **Asset** | Un'attività che si può vendere: software, sito, app con i suoi clienti e ricavi. |
| **Tasso base** | Quota di progetti simili che raggiunge l'obiettivo, prima di considerare le specificità del caso. |
| **Fasce di probabilità** | Usate per gli obiettivi A e C: bassa < 5%, media 5-15%. |
| **Acquire.com, Flippa, Empire Flippers, FE International** | Piattaforme e intermediari per comprare e vendere piccoli business online. |
| **Revenue share** | Accordo in cui si gestisce un prodotto altrui dividendo i ricavi, senza comprarlo. |
| **Leva di prezzo** | Aumentare i prezzi di un prodotto comprato, che il venditore aveva lasciato fermi. |
| **Prelievo (fiscale)** | Quota del margine che va in tasse prima di arrivare in tasca al founder. |
| **Ricalibrare** | Rivalutare un punteggio del primo giro con le regole e i fatti emersi nel secondo giro. |
| **k€ / k$ / M$** | Migliaia di euro / migliaia di dollari / milioni di dollari. |
| **Screening** | Prima selezione delle idee con criteri sì/no. |
| **TrustMRR** | Sito che raccoglie i ricavi ricorrenti dichiarati da piccoli software. |
| **RSA** | Residenza sanitaria assistenziale per anziani. |
| **Co-parenting** | Gestione condivisa dei figli tra genitori separati. |
| **Protocollo anti-bias** | Regole per evitare che le preferenze dell'utente influenzino la valutazione (vedi [[Protocollo di discovery]]). |
| **F1-F5, C1 (screening B2C)** | Codici dei candidati dello screening B2C (es. F1 nidi, C1 trova-bonus); da non confondere con i criteri C1-C11 della scala. |
| **SDE** | *Seller's Discretionary Earnings*: utile di un piccolo business prima del compenso del proprietario che lo gestisce. È la base su cui si calcola il prezzo di acquisto. |
| **Multiplo** | Prezzo di acquisto diviso per l'utile annuo (o per l'SDE). "3x" = tre anni di utile. |
| **ARR / MRR** | Ricavi ricorrenti annui / mensili. |
| **Micro-SaaS** | Piccolo software venduto in abbonamento online. |
| **Plugin / app di marketplace** | Estensione venduta dentro uno store di piattaforma (Shopify, WordPress, Atlassian), che porta i clienti. |
| **Atlassian Connect / Forge** | Due tecnologie per le app Atlassian: Connect va in dismissione (31/01/2027), le app vanno migrate a Forge. |
| **Feed** | Flusso di dati aggiornato in modo automatico: per esempio il catalogo con prezzi e disponibilità che un fornitore dà ai rivenditori, o un feed RSS di articoli. |
| **RSS** | Formato standard con cui un sito pubblica l'elenco dei suoi nuovi articoli. |
| **Operatore** | Persona che gestisce l'attività al posto del founder (a tempo pieno o part-time). |
| **Repository** | Archivio di file su GitHub che contiene questa wiki e i documenti di lavoro. |
| **EAN / OEM** | EAN: codice a barre standard di un prodotto. OEM: codice del produttore originale (es. ricambi). |
| **Matching** | Riconoscere lo stesso prodotto su siti diversi. |
| **OTA** | *Online travel agency*: agenzie di viaggio online (GetYourGuide, Booking…). |
| **Rate shopper** | Strumento che rileva le tariffe dei concorrenti. |
| **Actor (Apify)** | Programma di scraping pubblicato sul marketplace Apify, pagato a uso. |
| **API** | Interfaccia per ottenere dati da un servizio in modo automatico. |
| **LLM** | Modello linguistico come Claude o ChatGPT. |
| **Pipeline** | Catena automatica che raccoglie, pulisce e aggiorna dati. |
| **SEO programmatica** | Siti con migliaia di pagine generate da dati, per farsi trovare su Google. |
| **AI Overview** | Risposta generata dall'AI mostrata da Google sopra i risultati. |
| **CTR / RPM / eCPC** | Percentuale di clic; ricavo ogni 1.000 visite; guadagno medio per clic di affiliazione. |
| **Affiliazione** | Commissione su una vendita fatta da un sito partner. |
| **Lead** | Contatto di un potenziale cliente venduto a un'azienda. |
| **GEO** | Ottimizzazione della visibilità di un marchio nelle risposte delle AI. |
| **Riserva forense** | Attività che per legge possono svolgere solo gli avvocati. |
| **Art. 2105 c.c.** | Obbligo di fedeltà del dipendente: non fare concorrenza al datore. Per la Cassazione (sent. 19096/2013) basta anche preparare un'attività concorrente. |
| **SRL** | Società a responsabilità limitata. |
| **Sessioni S1-S9, R2** | Le sessioni di ricerca: S7-S9 sono quelle del filone famiglia; S1-S6 primo giro (una per gruppo di ipotesi), R2 secondo giro. I loro rapporti integrali sono in `Rapporti/`. |
